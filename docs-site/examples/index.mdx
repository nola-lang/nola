The repository includes the example projects below. Most pair a `.tsi` module with a plain TypeScript entry point in `src/main.ts` and use a mock provider, so you can run them without an API key.

Four examples are a single `.tsi` file with `src/main.tsi` as the entry point: `feature-extraction` and `function-calling`, which replay recorded answers from a committed ledger, `agent-loop`, which runs on the mock provider, and `triage-ticket`, whose default config calls typesafe.ai (the example explains how to switch to a mock provider).

The scaffolder's templates are these examples. Every template except `empty` is copied from the repository at the release tag that matches the CLI's version, so `npm create nola` needs network access for them; the first menu lists `feature-extraction`, `function-calling`, `agent-loop`, `typescript-interop` and `triage-ticket`, and *More examples…* the rest of the ones with a scaffold command below.

Every example types its asks with the colon spelling, `` ask `…`: T ``; `<T>` means the same thing. See [Extractors](/docs/language/extractors/#the-angle-bracket-spelling).

## Running an example

Use a scaffold command from the table, or run an example from a repository checkout. The examples are npm workspaces, so install and build at the root first:

```sh
git clone https://github.com/nola-lang/nola
cd nola && npm install && npm run build
cd examples/extract-person
npx nola-lang run src/main.ts      # mock provider, deterministic
```

To use a real model, open the example's `nola.config.ts`. Most include a commented config for `openai({ model: "gpt-5-mini" })`, which reads `OPENAI_API_KEY`. For the others, replace `mockProvider(...)` with your chosen provider. See [Providers](/docs/config/providers/).
