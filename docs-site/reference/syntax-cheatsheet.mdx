## Values in an instruction

| Construct | Example | Page |
| --- | --- | --- |

## All of it in one file

```tsi
// cheatsheet.tsi
import { createTicket } from "./tickets.js";

export type Severity = "low" | "medium" | "high";
export interface Person {
  name: string;
  /** age in years */
  age: number;
}

export const nameIntent = ..`the user's full name`: string;

export infer function triage(.ticket: string, fallback: Severity) {
  `Triage the ticket. Rules: never invent ticket ids.`
  const person = ask `the person described in the ticket`: Person;
  const severity = ask with careful `the severity of the ticket`: Severity;
  const id = ask createTicket(`a short ticket title for ${person.name}`: string, 2);
  const name = ask nameIntent;
  return { person, severity: severity || fallback, id, name };
}
```

```ts
// tickets.ts
export async function createTicket(title: string, priority: number): Promise<string> {
  return `${title}:${priority}`;
}
```

## Not valid

These forms are not supported: `async infer function`, `export default infer function`, `` infer function f`…`(…) `` (the marker slot is reserved), `infer` on methods or arrows, `fn(..)`, `var .x = …`, `..name` on a parameter, and `ask` as an identifier. See [Restrictions](/docs/language/restrictions/) for details.

Avoid identifiers starting with `__nola`. The compiler uses that prefix in generated code; shadowing one can break the output without producing a diagnostic.
